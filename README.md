<br/>

## 📌 개요

유튜브 쇼츠 플랫폼에서 인기 콘텐츠의 트렌드를 분석하고 시각적으로 제공하는 웹 애플리케이션입니다.

<br/>

## 📄 관련 논문

| 항목 | 내용 |
|:---:|:---|
| 제목 | 유튜브 쇼츠 콘텐츠 트렌드 분석 |
| 게재지 | IJIBC (International Journal of Internet, Broadcasting and Communication) |
| 상태 | ✅ 게재 완료 |

<br/>

## ✨ 주요 기능

- 📈 유튜브 쇼츠 콘텐츠 트렌드 데이터 시각화
- 🔍 카테고리별 트렌드 분석 결과 제공
- 🖥️ React Router 기반 페이지 라우팅

<br/>

## 🛠 기술 스택

| 분류 | 기술 |
|:---:|:---:|
| Frontend | React, JavaScript |
| Routing | React Router DOM v6 |
| Styling | CSS |

<br/>

## 🚀 시작하기

```bash
# 레포지토리 클론
git clone https://github.com/ye-eun-min201/youtubeshorts.git

# 디렉토리 이동
cd youtubeshorts

# 패키지 설치
npm install

# 로컬 실행
npm start
```

> 브라우저에서 `http://localhost:3000` 으로 접속하세요.
